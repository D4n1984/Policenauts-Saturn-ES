# Policenauts para Sega Saturn en español

Parche de traducción al español de España para la edición japonesa de *Policenauts* de Sega Saturn. La versión 1.5 incluye los **tres discos**.

## Qué necesitas

- Una copia propia japonesa de cada disco, extraída en un archivo CUE y dos archivos BIN.
- Un ordenador con Windows, Linux o macOS. En Linux y macOS se necesitan Python 3, xdelta3 y chdman.
- Un emulador o dispositivo compatible con imágenes CHD y cambio de disco.

El paquete incluye las herramientas para Windows y no requiere instalar por separado la traducción inglesa. Los archivos del juego no están incluidos.

## Descargar y aplicar

1. Descarga el ZIP de la [versión 1.5](https://github.com/D4n1984/Policenauts-Saturn-ES/releases/tag/v1.5).
2. Descomprímelo en una carpeta.
3. Sigue las [instrucciones de aplicación](parche/README_ES.md), también incluidas en el ZIP como `README_ES.md`.

El aplicador crea y verifica un CHD para cada disco. El propietario ha completado una partida del disco 1 con la versión anterior; las correcciones recientes, los demás discos, los cambios de disco, las voces, los vídeos y los enlaces requieren más pruebas en juego. La demostración inicial presenta problemas de texto también observados en la referencia inglesa.
