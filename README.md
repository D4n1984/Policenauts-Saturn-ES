# Policenauts para Sega Saturn en español

Parche de traducción al español de España para la edición japonesa de *Policenauts* de Sega Saturn. La versión 1.1 es experimental e incluye los **discos 1 y 2**; el disco 3 todavía no está disponible.

## Qué necesitas

- Una copia propia japonesa de cada disco, extraída en un archivo CUE y dos archivos BIN.
- Un ordenador con Windows, Linux o macOS. En Linux y macOS se necesitan Python 3, xdelta3 y chdman.
- Un emulador o dispositivo compatible con imágenes CHD y cambio de disco.

El paquete incluye las herramientas para Windows y no requiere instalar por separado la traducción inglesa. Los archivos del juego no están incluidos.

## Descargar y aplicar

1. Descarga el ZIP de la [versión experimental 1.1](https://github.com/D4n1984/Policenauts-Saturn-ES/releases/tag/v1.1).
2. Descomprímelo en una carpeta.
3. Sigue las [instrucciones de aplicación](parche/README_ES.md), también incluidas en el ZIP como `README_ES.md`.

El aplicador crea y verifica un CHD para cada disco. No se ha completado una partida de prueba: el cambio al disco 2, sus voces, vídeos y enlaces requieren validación en juego. El rótulo gráfico del menú todavía muestra `Ver 1.0 ESP`; la demostración inicial presenta problemas de texto también observados en la referencia inglesa.
